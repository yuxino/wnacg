# WNACG 应用图标重构

## 已证实的问题

当前母版是触及画布四边的透明圆。它在 macOS 中会被再次放入浅灰圆角底板：用户截图里内圆直径只占外壳约 73–74%，形成双层容器。角色源图本身并不小，问题来自整体轮廓和系统合成，而不是角色画风。

Kiri、Fuwa、Mimi 与 Satori 的当前有效 macOS 产物虽然生成方式不同，但 Finder 或 `NSWorkspace` 解析后的不透明外壳都约占画布 80–82%，并呈单层白色或近白色 squircle。共同语言是低饱和角色、清楚的脸部与主道具、轻边缘和稳定安全区，而不是新的主题色、渐变、玻璃或重阴影。Koma 当前没有桌面打包链，因此只作为高对比 Web 小图参考，不作为 macOS 外壳依据。

## 采用的构图

保留现有 Kiri 角色、黑白兔耳、淡紫眼睛、漫画书与环形漫画纹样，不重新生成角色。把同一图像缩放到约 80% 画布，并放入与生态应用一致的中性白 squircle。圆环与外壳边界接近，使它成为内部纹样而不是第二层图标；脸、眼睛、兔耳和书仍是 32–64 px 下的主要识别点。

不加入 `wnacg` 字标。Kiri/Fuwa 的小写字标在小尺寸下会先退化，而 WNACG 已有更独特的兔耳加漫画组合。也不采用只剩头像的近景方案，因为它会削弱“漫画阅读器”的产品识别。

## 资产与验证

`docs/brand/kiri/kiri-app-icon-source.png` 是桌面母版；脚本只保留并同步 Tauri 实际引用的 32、128、256 PNG、macOS ICNS、Windows ICO 和 public 128 PNG。生成清单绑定源图与派生文件哈希，构建前校验 alpha、安全区、尺寸集合和引用。

验证分为四层：源文件与小尺寸检查；真实 Tauri app bundle；使用独立名称和 bundle identifier 的测试包，避免覆盖正式安装；Finder/Dock 等 macOS 实际显示。打包、签名、安装、启动和可见结果分别报告，不用其中一项代替另一项。
