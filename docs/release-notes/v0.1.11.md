This is the signed updater bootstrap release.

- Adds the signed updater foundation, release notes, real download-progress
  states, retryable failures, and controlled relaunch behavior.
- Keeps downloads and installation user initiated; no background download or
  silent installation is added.
- Keeps the GitHub Releases page only as an error-recovery path.

This version and later private releases require manual download while the
repository remains private. The application does not embed a repository token;
sign in to GitHub and use the private Releases page.
